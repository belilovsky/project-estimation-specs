# Задания для независимой оценки проектов

Готовые описания продуктов, с которыми можно спросить у разных разработчиков: **«Сколько стоит создать и передать такой продукт?»** Здесь нет наших часов, ставок или желаемой цены. Стоимость альтернативной разработки не определяет автоматически цену продажи или аренды.

Это каталог подготовленных заданий, а не перечень всех наших проектов. Другие продукты пока не оценены здесь. Дата комплекта не означает проверки сегодняшнего сайта или получения рыночных предложений.

Подрядчику достаточно открыть карточку нужного проекта, затем задание и форму предложения. Не нужно изучать общую методику, чтобы ответить на готовый запрос.

## Добавить следующий проект

1. Создайте черновик из общих шаблонов, Node.js 20+:

   ```sh
   node scripts/new-project.mjs example-project "Название проекта"
   ```

   `example-project` — пример имени, не ещё один оценённый продукт. Команда создаёт только новую папку в `projects/`, не читает исходники продуктов и ничего не публикует.

2. Заполните состав, измеримые объёмы, материалы, риски и условия по [порядку подготовки](docs/preparing-a-project.md). Уберите неприменимые требования; неизвестное обозначьте явно.
3. Выполните ручную проверку и команды ниже. После проверки опубликуйте только разрешённые файлы и добавьте ссылку в таблицу проектов. Статус сам не повышается.

```sh
node scripts/validate.mjs
node scripts/test.mjs
```

Проверка закреплённого внешнего комплекта через публичный GitHub, с обращением к сети:

```sh
node scripts/validate.mjs --remote
```

## Принципы

- Описываем результат, а не доказываем сложность. Готовые CMS, библиотеки, сервисы и ИИ разрешены; собственные базовые технологии не требуются.
- Общие функции, автоматизированные пакетные операции и проверки учитываются один раз. Число строк задания не равно числу отдельных внедрений.
- Редакционные оригиналы, переводы, нормативные тексты и повторные форматы различаются. Первоначальное наполнение и обновления оцениваются отдельно.
- 22 категории рисков — проверка применимости, а не обязательная закупка 22 систем защиты.
- Неподтверждённое не называется работающим, черновик — готовым запросом, экспертная оценка — замером или рыночной ценой.
